# 外贸业务管理系统（HelloOrder）需求文档

**版本**: 1.0  
**日期**: 2026年1月29日  
**项目目录**: HelloOrder

---

## 一、项目概述

### 1.1 业务背景

本公司为海外虾皮（Shopee）等电商平台商家提供**订单找货与代运营服务**，核心流程包括：

- 为商家店铺商品**报价**，商家确认后由外贸业务员通过**店小秘**等工具管理其店铺；
- **每日维护订单**，根据订单在**中国1688**找货；
- 根据商家每日订单生成**报价单**，发送给商家确认；
- 商家**付款**后，根据订单生成**采购表**，安排采购；
- 货物到仓后**分拣、打印面单、打包、发货、跟踪及售后**。

### 1.2 建设目标

建设一套 **Web 外贸业务管理系统**，实现：

- 全流程线上管理：报价 → 订单 → 采购 → 仓储 → 发货 → 跟踪 → 售后；
- **权限与角色**管控：外贸业务员、助理、老板、系统管理员；
- **经营数据可视化**：公司销量、盈利、各业务员/助理**提成**计算；
- 提升效率、减少人工重复操作、节省时间。

## 二、用户角色与权限

### 2.1 角色定义

| 角色         | 说明                     | 主要职责 |
|--------------|--------------------------|----------|
| 系统管理员   | 系统配置与用户管理       | 用户/角色/权限、系统参数、数据字典 |
| 老板         | 公司负责人               | 查看全公司销量与盈利、提成报表、审批与监督 |
| 外贸业务员   | 对接商家、负责报价与订单 | 商家管理、报价单、订单维护、店小秘对接 |
| 助理         | 业务员助理               | 协助找货、采购跟进、部分订单与发货操作（受业务员/权限约束） |

### 2.2 权限需求（概要）

- **系统管理员**：用户增删改、角色分配、权限配置、系统参数、日志查看。

### 2.3 用户管理模块功能需求

用户管理仅系统管理员可操作，需支持以下功能（与权限、角色配置一致）：

| 功能 | 说明 |
|------|------|
| **查询** | 用户列表分页、按用户名/姓名/角色筛选；展示用户名、姓名、角色、状态、创建时间。 |
| **新增** | 新增用户：用户名、姓名、初始密码、分配角色；用户名唯一。 |
| **修改** | 修改用户：姓名、角色、状态（正常/禁用）；可选修改密码。 |
| **删除** | 删除用户：软删除（置为禁用）或物理删除；禁止删除当前登录管理员自身。 |
| **权限设置** | 通过为用户分配**角色**实现权限控制；角色包括系统管理员、老板、外贸业务员、助理，对应设计文档中的 RBAC 与数据范围。 |

### 2.4 角色管理模块功能需求

角色管理仅系统管理员可操作，需支持以下功能：

| 功能 | 说明 |
|------|------|
| **查询** | 角色列表，展示角色编码、名称、数据范围、创建时间；支持按名称/编码筛选。 |
| **新增** | 新增角色：角色编码、角色名称、数据范围（全部/本部门/本人）；编码唯一。 |
| **修改** | 修改角色：名称、数据范围。 |
| **删除** | 删除角色：若有用户绑定该角色则禁止删除，或先解除绑定再删。 |
| **页面权限设置** | 为角色分配可访问的**页面/菜单权限**（对应 sys_permission 中 type=菜单 的权限）；支持树形勾选，保存后该角色用户仅能看到并访问已勾选菜单。 |

### 2.5 页面权限管理模块功能需求

页面权限（菜单/按钮/接口权限）仅系统管理员可操作，需支持以下功能：

| 功能 | 说明 |
|------|------|
| **查询** | 权限列表，展示权限编码、名称、类型（菜单/按钮/接口）、路径、排序；支持按类型、名称/编码筛选。 |
| **新增** | 新增权限：编码、名称、类型、父级（可选）、路径（可选）、排序；编码唯一。 |
| **修改** | 修改权限：名称、类型、父级、路径、排序。 |
| **删除** | 删除权限：若被角色引用需先解除角色-权限关联再删，或禁止删除并提示。 |

- **老板**：全公司/全业务员维度的销量、收入、成本、利润报表；提成规则与提成明细；不可改业务数据，可查看与导出。
- **外贸业务员**：本人负责的商家、报价单、订单、采购单、发货与售后；可分配任务给其助理。
- **助理**：被分配的任务与订单、找货与采购跟进、发货操作（按权限）；不可看其他业务员数据，不可改提成与全局报表。

（详细权限矩阵见设计文档。）

## 三、业务流程需求

### 3.0 商家店铺与商品管理

业务员与商家沟通达成协议后，商家会将其**店铺**及店铺内的**商品**信息提供给公司；公司需将店铺与商品录入系统，供后续找货、报价、运费计算等使用，且**订单需能明确归属到具体店铺**。

#### 3.0.1 商家店铺

| 需求项 | 说明 |
|--------|------|
| **概念** | 一个商家（Merchant）可拥有多个**店铺**（如不同平台店铺、同一平台多店）。订单、报价、找货等均需能区分「来自哪个店铺」。 |
| **店铺主数据** | 店铺需维护：店铺名称、所属商家、平台（如 Shopee/Lazada）、店铺链接/标识、备注、状态（正常/停用）。归属与权限同商家：仅负责该商家的业务员（及其助理）可维护其店铺。 |
| **与订单关联** | 创建/导入订单时需选择或默认该商家的某一店铺；订单列表与详情需展示所属店铺；报表与找货可按店铺维度筛选。 |
| **与商家关系** | 商家管理详情下可维护其下属店铺列表（增删改查）；新建订单时若商家仅有一个店铺可默认选中。 |

#### 3.0.2 商品管理

| 需求项 | 说明 |
|--------|------|
| **概念** | 商品为**店铺维度**的主数据：将商家提供的店铺商品全部录入系统，形成「店铺商品库」，供找货表、报价表、运费计算等复用。 |
| **商品主数据** | 商品需维护：所属店铺、商品编码（SKU）、商品名称、规格、主图/图片链接、平台链接、重量（用于运费）、备注、状态。可选：默认 1688 找货链接、建议采购价、建议售价。 |
| **使用场景** | （1）**找货表**：按商品匹配或新建找货记录，维护 1688 链接与采购价；（2）**报价/订单**：选择店铺商品快速带出 SKU、名称、规格、重量等；（3）**运费计算**：按商品重量与数量参与运费估算；（4）**采购**：采购单可关联到商品及已有 1688 链接。 |
| **归属与权限** | 商品归属店铺、店铺归属商家，故数据范围与商家一致：仅负责该商家的业务员（及其助理）可查看与维护该商家下各店铺的商品。 |
| **与店铺关系** | 在商家详情或店铺详情下维护「店铺商品」列表；支持按 SKU/名称筛选、分页；支持批量导入（后续扩展）。 |

#### 3.0.3 需求优先级

| 优先级 | 内容 |
|--------|------|
| P0 | 商家店铺 CRUD、订单关联店铺（可选填，列表与详情展示店铺）、按店铺筛选订单。 |
| P0 | 商品主数据 CRUD（归属店铺）、商品列表按店铺筛选、订单/报价行可关联或引用商品信息（如 SKU/名称/规格/重量）。 |
| P1 | 找货表、报价表、运费计算中正式引用商品表（带出 1688 链接、重量等）；采购单明细关联商品。 |

---

### 3.1 商家与报价

- **商家管理**：维护海外商家信息（名称、平台、店铺、联系人、结算方式等），归属到具体外贸业务员。
- **商品报价**：为商家店铺商品在 1688 找货并维护报价（含找货表、报价表）；支持按商家/商品生成报价单，发送给商家确认。
- **报价单**：根据每日或指定时间段的订单/需求汇总生成报价单，支持导出（如 Excel/PDF），记录“已发送/已确认/已拒绝”等状态。

### 3.2 订单管理

- **订单来源**：与店小秘等工具对接或手工导入，订单归属到商家与业务员。
- **订单维护**：每日同步/导入订单，状态包括：待报价、已报价待确认、已确认待付款、已付款、已生成采购、采购中、到仓待发、已发货、已完成、售后/异常。
- **找货**：根据订单在 1688 找商品，维护 1688 链接、规格、采购价、建议售价等，支持找货表/报价表生成。

### 3.3 采购管理

- **采购单生成**：商家付款成功后，根据订单表汇总生成采购表（按 SKU/规格、数量、1688 链接等）。
- **采购执行**：分配采购负责人，记录采购进度、供应商、快递单号、到货情况。
- **与订单关联**：采购单与订单/报价可追溯，便于对账与售后。

### 3.4 仓储与发货

- **入库**：采购到货后登记入库，支持按采购单、按 SKU 入库。
- **分拣**：按订单进行分拣，系统支持分拣任务与进度。
- **面单与打包**：按订单打印快递/包裹面单，记录包裹重量、快递公司、单号。
- **发货**：确认发货后更新订单状态，写入物流单号，进入跟踪环节。

### 3.5 物流跟踪与售后

- **物流跟踪**：记录并展示物流状态，可对接快递接口或手工维护。
- **售后**：登记售后类型（退货、换货、补发、赔偿等）、处理人、处理结果，与订单关联。

## 四、经营与提成需求

### 4.1 老板看板

- **销量**：按日/周/月/年统计订单数、件数、金额（可按平台、商家、业务员维度）。
- **盈利**：收入（商家付款）与成本（采购、物流、其他）统计，毛利与净利。
- **提成看板**：各外贸业务员、助理的销量与提成金额，支持按时间段筛选与导出。

### 4.2 提成规则

- 支持配置提成规则（如按销售额比例、按单量阶梯、按利润比例等）。
- 业务员与助理可不同规则；可区分“业务员本人业绩”与“助理协助业绩”的分配比例。
- 系统根据订单与规则**自动计算提成**，老板可审核、调整（留痕）后确认。

## 五、非功能需求

### 5.1 性能与可用性

- 支持至少 50 个并发用户正常使用；
- 关键列表与报表响应时间 ≤ 3 秒；
- 系统可用性目标 99% 以上（按业务时间计）。

### 5.2 安全

- 登录认证与会话管理，支持强密码策略；
- 按角色与数据归属做权限控制，敏感操作留操作日志；
- 敏感数据（如金额、客户信息）传输与存储需加密。

### 5.3 扩展与集成

- 预留与**店小秘**、**1688**、**快递**等第三方对接的扩展点；
- 支持 Excel 导入导出（订单、报价单、采购表等），格式可配置。

### 5.4 审计与合规

- 关键业务操作（报价确认、付款确认、采购单生成、发货、提成确认）记录操作人、时间、前后值；
- 支持按时间范围导出审计日志。

## 八、新增需求（商品与物流、订单转换）

### 8.1 商品管理增强（找货表/报价表支撑）

业务需要根据虾皮店铺商品在国内找货报价，形成**找货表**、**报价表**（含主报价表、upsell 报价表）。商品主数据需支持：

| 需求项 | 说明 |
|--------|------|
| **重量与尺寸** | 记录商品重量（支持克 g 与 kg），以及包装尺寸（长、宽、高，单位 cm），用于计算物流运费与计费重量。 |
| **中英文名称** | 商品名称支持中文名、英文名，便于与报价表（产品中文名字、产品英文名字）对应。 |
| **找货与报价关联** | 商品可维护 1688 采购链接、客户链接、厂家链接、款式、材质、尺码表、实际包装说明等，便于导出或生成找货表、报价表。 |
| **与现有商品模块关系** | 在现有「店铺商品」CRUD 基础上扩展字段与导出能力，不改变归属（仍按店铺、商家权限）。 |

参考数据格式见：`docs/convertedData/LG-Le/Quotation/` 下找货表、瑜伽裤报价表、upsell 报价表 CSV 的列结构。

### 8.2 快递公司与物流管理

用户需要维护各快递公司的**实时运费信息**，以及**寄往不同国家的快递价格与时效**，用于报价与成本核算。

| 需求项 | 说明 |
|--------|------|
| **快递公司主数据** | 维护快递公司名称、编码、联系方式、备注、状态（启用/停用）。 |
| **国家与运费** | 按「快递公司 + 目的国家」维护：单价或阶梯价、时效（如 6–11 个工作日）、计费规则（按重量/体积）等；支持多国家（如 FR、BE、CH、LU、IT 等）。 |
| **使用场景** | 报价表生成时按商品重量与目的国匹配运费；发货时选择快递公司并记录单号与费用。 |
| **权限** | 建议系统管理员或业务负责人维护；业务员、助理可查看与引用。 |

### 8.3 订单文件转换

用户可上传指定格式的 Excel，由系统完成转换并下载结果，对应现有线下「OrderConverterEXE」的流程：

| 输入 | 说明 |
|------|------|
| **报价新文件** | 如「LG-le docteur 2026.1.21号 瑜伽裤报价新.xlsx」，用于匹配报价与找货信息。 |
| **Tracking & Cost 源文件** | 如「LG-Lｅ Ceralia(瑜伽裤）-2 Jan22th tracking & cost.xlsx」，订单明细与物流成本来源。 |

| 输出 | 说明 |
|------|------|
| **onlyShip_…tracking & cost.xlsx** | 使用报价表中的「Ship to XX」列计算运费与成本。 |
| **…tracking & cost.xlsx** | 使用报价表中的「Total to XX」列计算总价。 |
| **…采购.xlsx** | 按订单汇总生成的采购表（SKU、应采数量、采购链接等），可结合找货表匹配商品名与链接。 |

| 需求项 | 说明 |
|--------|------|
| **操作方式** | 在系统内提供「订单文件转换」入口：上传报价新 Excel + Tracking&Cost Excel，选择或自动识别商家/店铺，执行转换后提供上述三份 Excel 的下载。 |
| **依赖** | 转换逻辑依赖报价表、找货表数据（可来自系统内商品与报价数据，或用户上传的报价新文件中内嵌/关联数据）。 |
| **权限** | 业务员、助理（有权限的）可执行转换；管理员可查看转换记录（可选）。 |
