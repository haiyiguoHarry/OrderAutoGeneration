# 项目运行说明

## 当前状态

项目代码已完全实现，使用完全免费的 NuGet 包（ClosedXML、CsvHelper 等）。

## 运行步骤

### 1. 恢复 NuGet 包

在有网络连接的环境下，运行：

```bash
cd OrderConverterEXE
dotnet restore
```

### 2. 构建项目

```bash
dotnet build
```

### 3. 运行项目

```bash
dotnet run
```

## 如果遇到网络问题

### 方案 1：检查网络连接

确保可以访问 https://api.nuget.org

### 方案 2：使用国内 NuGet 镜像源

如果在中国大陆，可以配置国内镜像源：

```bash
# 添加 NuGet 镜像源（使用阿里云）
dotnet nuget add source https://mirrors.aliyun.com/nuget/v3/index.json --name aliyun

# 或者使用腾讯云
dotnet nuget add source https://mirrors.cloud.tencent.com/nuget/ --name tencent
```

### 方案 3：手动下载包

如果网络环境受限，可以：

1. 在有网络的环境下运行 `dotnet restore`
2. 将 `obj` 和 `bin` 目录复制到目标环境
3. 或者使用 `dotnet publish` 创建自包含的可执行文件

## 项目依赖

项目使用以下完全免费的 NuGet 包：

- **ClosedXML 0.104.0** - Excel 操作（MIT 许可证）
- **CsvHelper 33.0.1** - CSV 处理（Apache 2.0 许可证）
- **Microsoft.Extensions.Hosting 8.0.1** - 后台服务
- **Microsoft.Extensions.Logging 8.0.1** - 日志记录
- **Microsoft.Extensions.Logging.Console 8.0.1** - 控制台日志
- **System.Text.Encoding.CodePages 8.0.0** - 编码支持

## 运行要求

- .NET 8.0 SDK 或更高版本
- 网络连接（首次运行需要下载 NuGet 包）

## 程序功能

程序启动后会：

1. 自动监控 `docs/sourceData` 目录
2. 每 10 秒检查一次新文件
3. 自动转换 XLSX 文件为 CSV/Excel 格式
4. 对 Orders 目录进行特殊处理（添加列、计算等）
5. 转换后删除原文件

按 `Ctrl+C` 可以停止程序。

## 日志

程序运行日志会保存到 `xlsx_converter.log` 文件中，同时也会在控制台显示。
